## 🚀 Panduan Belajar

1. **Urutan Belajar**: Disarankan mempelajari modul secara berurutan mulai dari Bagian 1 (Front-End dasar) ke Bagian 2 (Back-End PHP & MySQL), lalu menguji pemahaman dengan membangun proyek di Bagian 3.
2. **Praktik Mandiri**: Buka tautan materi terkait untuk membaca penjelasan teori dan salin/praktikkan contoh kode ke dalam editor lokal (seperti VS Code).
3. **Kebutuhan Lingkungan**:
   - Web Browser (Chrome / Firefox / Edge)
   - Code Editor (Visual Studio Code / sejenisnya)
   - Web Server Lokal & MySQL (XAMPP / Laragon / PHP Built-in Server)
